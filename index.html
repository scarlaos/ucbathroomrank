Developer Specs & Technical Overview

Portfolio Highlights

UC Restroom Index is a single-page interactive UI application demonstrating web mapping integrations, client-side state management, and real-time local data persistence. Designed as a polished, high-utility campus facility review platform.

Technical Architecture:

  • Interactive Map Integration: Leaflet.js with custom styled markers, coordinate popups, dynamic bounds zooming, and geolocation services.
  • Persistence Layer: Static JSON data loaded with Fetch, making updates simple to review and publish through GitHub Pages.
  • Dynamic UI State: Real-time filtering by building, star ratings, accessibility, feminine products, and text searching.
  • Theme System: Tailored University of Cincinnati Bearcat branding (#E00122 Red & Black palette) with responsive mobile design.

Quick Editing Tip:

Click "Rate Restroom" in the top header to add your own real reviews as you visit new restrooms around UC campus. You can also click on any card to update existing entries!
